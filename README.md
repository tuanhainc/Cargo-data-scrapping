# Cargo-data-scrapping

Previous project in my last job scrapping data from a [website](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=http://cangvuhanghaivungtau.gov.vn/Index.aspx%3Fpage%3Dkhddt%26d%3D0&ved=2ahUKEwjXu_XEpY2NAxXpa_EDHZ-yISgQFnoECBgQAQ&usg=AOvVaw2b7fDUdLOB6TLDMN8Bzp3c) , which provides information of upcoming vessels in Vietnam. That website is unfortunately no longer accessible so I used another, but very similar [website](https://vungtaupilot.com/Ke-Hoach-Dan-Tau) to demonstrate how I extracted vessels information from different dates and compiled them into a single Excel file. Note that the original webiste was Javascript-rendered, while the newer one has static HTML content. The orignial Python script, I used a mix of Selenium and BS4 for rendering and interacting with the site. The updated version only require HTML parsing.
